# ラピッドナイン（試作版）

1から9まで、撃ち抜け。ナンプレのルールで「数字の場所」を見抜いて撃つ、スマホ向けパズルシューティング。

`index.html` を開くだけで遊べます（ビルド不要・1ファイル）。

## モード
- **ラピッドナイン**：3×3の的に、1→9の順で「入る場所」を撃つ
- **スナイパー**：的は1マスだけ。そのマスに「入る数字」を1〜9の弾から選んで撃つ（1画面1的）
- **クイックドロー**：20秒の早撃ち。見る情報を削り、どれだけ速く撃てるかを突き詰めたモード

## ルール（ラピッドナイン）
- 9×9の盤のうち、撃てるのは真ん中の3×3（的）だけ
- 画面に出る数字（1→9の順）が入るマスをタップする。数字は選ばない
- 周りの数字と同じ行・列には、同じ数字は入らない
- 的に最初から入っている数字は飛ばす（難易度で数が変わる）
- 9まで撃ち切ると的が砕け、次の的へ
- 外すとコンボが0に戻る

## 構成
| ステージ | 名前 | 的に最初から入っている数字 | 備考 |
|---|---|---|---|
| 1 | EASY | 5個 | ガイド線つき |
| 2 | NORMAL | 3個 | |
| 3 | NORMAL+ | 2個 | |
| 4 | HARD | 1個 | |
| 5 | EXPERT | 0個 | |

1ステージ＝的10枚。5ステージでクリア。

## ルール（スナイパー）
- 盤のどこかに的が1つ置かれる
- 的と同じ行・列・3×3ブロックにある数字を除くと、入る数字が1つに決まる
- 画面下の弾（電話のキー配置：1 2 3／4 5 6／7 8 9）から、その数字を選んで撃つ。外すとコンボが0に戻り、理由の数字が赤く光る
- 始める前に難易度を選ぶ
  - かんたん：3×3だけ。8つの数字にない数字を撃つ
  - ふつう：3×3が3つ（横か縦にランダム）。行（列）とブロックで見抜く
  - むずかしい：9×9。行・列・ブロックで見抜く
- 1ステージ＝的10枚、5ステージでクリア。ふつう・むずかしいはステージ1だけガイドつき
- ふつう・むずかしいは、進むほど手がかりが減り、関係ない数字（ノイズ）が増える
- ベストスコアは難易度ごとに記録
- ノーミスで的を5枚続けて撃つとフィーバー

## ルール（クイックドロー）
- 数字の種類を4・6・9から選ぶ（盤は4×4／6×6／9×9）
- 的はいつも画面の同じ場所にある。表示するのは的と同じ行・列・ブロックのマスだけ
- 手がかりは、答えを1つに決めるのに必要な最小限だけ
- 数字とボタンは数字ごとに同じ色
- 制限時間は20秒。当てるとすぐ次の問題。外すと0.4秒ボタンが効かなくなる（連打対策）
- スコア＝命中ごとに 100 ＋ 速射ボーナス（0〜200。2秒以内に撃つほど高い）＋ 連続ボーナス（連続1回につき10、上限200）
- 結果はスコアと内訳（命中・速射ボーナス・連続ボーナス）、1発の平均時間、最速、最大連続、命中率、ミス。ベストスコアは種類ごとに記録

## スコア
- 命中：100 ＋ 速射ボーナス（最大100、3秒以内）＋ コンボ×10（上限300）
- 的の破砕：300（ノーミスなら500）
- ノーミスで的を3枚続けて砕くと10秒間フィーバー（得点2倍）

## 問題生成
毎回ランダム生成。ラピッドナインは、完成盤を作り、的の周りの手がかりを1つずつ削りながら、
「どの数字も、その順番が来た時点で入る場所が1つに絞れる」状態を保つ。
スナイパーは、的の行・列・ブロックの手がかりを削りながら、候補が1つだけの状態を保つ。

## 試作で調整したい点
- ランダム生成か固定の的か
- ステージごとの難易度の上げ方
- スコアとフィーバーの条件
- 音と振動の強さ
